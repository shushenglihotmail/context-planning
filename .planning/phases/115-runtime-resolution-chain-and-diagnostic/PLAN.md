# lib/runtime.js: workflow-start diagnostic aggregator + 5-step resolution chain + subagent-dispatch directive emission

Walk expanded phase DAG once at workflow start to collect distinct (role, skill_name) pairs. For each, run 5-step resolution chain: (1) sigil-fuzzy if name wrapped in parens, (2) exact match in role-filtered catalog, (3) manual-provider prompts[role] inlined into wave instruction, (4) generic subagent-dispatch directive (harness-agnostic 'dispatch a subagent with role: <role>, prompt: <phase.prompt>'), (5) bare phase prompt. Emit ONE consolidated diagnostic block before wave 1 grouped by status (resolved / fuzzy-matched-to-X with candidate list / fell-back-to-manual with cp config set hint). Cache resolved skills for the duration of the run. Integration tests cover each fallback layer + snapshot the diagnostic format.
